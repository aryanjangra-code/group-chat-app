# GroupChat — Real-time Socket.io Chat App

A minimal, beautiful single-room group chat built with **Node.js**, **Express**, and **Socket.io**.

## Features
- Real-time messaging (Socket.io WebSockets)
- Typing indicators
- Join / Leave notifications
- Online user list with count
- Mobile responsive
