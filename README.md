# GroupChat — A Real-time Chat Application



A minimal, beautiful, and responsive single-room group chat application built with **Node.js**, **Express**, and **Socket.io**.

## Live Demo

You can see a live version deployed on Railway:

**[https://group-chat-app-production-0ca0.up.railway.app/](https://group-chat-app-production-0ca0.up.railway.app/)**

---



## Features

- **Real-time Messaging:** Instant message delivery using Socket.io WebSockets.
- **User Authentication:** Simple username-based entry to the chat.
- **Typing Indicators:** See when other users are typing a message.
- **Join/Leave Notifications:** Get notified when a user connects or disconnects.
- **Online User List:** View a list of all currently active users and a total count.
- **Mobile Responsive:** A clean and functional interface on both desktop and mobile devices.

## Tech Stack

- **Backend:** Node.js, Express.js
- **Real-time Communication:** Socket.io
- **Frontend:** HTML, CSS, JavaScript

## Getting Started

Follow these instructions to get a copy of the project up and running on your local machine for development and testing purposes.

### Prerequisites

You need to have [Node.js](https://nodejs.org/) and [npm](https://www.npmjs.com/) (or yarn) installed on your machine.

### Installation

1.  **Clone the repository:**
    ```sh
    git clone https://github.com/your-username/groupchatapp.git
    cd groupchatapp
    ```

2.  **Install server dependencies:**
    ```sh
    npm install
    ```

3.  **Start the development server:**
    ```sh
    npm start
    ```

4.  Open your browser and navigate to `http://localhost:3000`.
